1단계 — Google 스프레드시트 만들기

1구글 드라이브(drive.google.com)에서 새 스프레드시트를 만드세요.

2시트 이름이 Sheet1인지 확인하세요 (기본값).

3첫 번째 행에 아래 헤더를 입력하세요:

타임스탬프  이름  직분/다락방  참석여부  메시지  기기ID

4주소창에서 스프레드시트 ID를 복사하세요:

https://docs.google.com/spreadsheets/d/여기가_시트_ID/edit

2단계 — Apps Script 작성 및 배포

1스프레드시트 상단 메뉴에서 확장 프로그램 > Apps Script를 클릭하세요.

2편집기에 기존 코드를 모두 지우고 아래 코드를 붙여넣으세요:

// ─────────────────────────────────────────
// 중종로공동체 RSVP Backend
// 아래 두 값을 반드시 수정하세요
// ─────────────────────────────────────────
const SHEET_ID  = '여기에_스프레드시트_ID_붙여넣기';
const ADMIN_PW  = 'admin1234';  // 원하는 비밀번호로 변경
const SHEET_NM  = 'Sheet1';

function doPost(e) {
  try {
    const data  = JSON.parse(e.postData.contents);
    const sheet = SpreadsheetApp.openById(SHEET_ID).getSheetByName(SHEET_NM);

    if (data.action === 'submit_rsvp') {
      // 기기 중복 확인
      const rows = sheet.getDataRange().getValues();
      for (let i = 1; i < rows.length; i++) {
        if (rows[i][5] === data.deviceId) {
          return json({ success: false, error: 'already_registered' });
        }
      }
      // 신규 등록
      sheet.appendRow([
        new Date().toLocaleString('ko-KR'),
        data.name,
        data.cellGroup  || '',
        data.attendance,
        data.message    || '',
        data.deviceId,
      ]);
      return json({ success: true });
    }
    return json({ error: 'unknown' });
  } catch(err) {
    return json({ error: err.message });
  }
}

function doGet(e) {
  try {
    if (e.parameter.action === 'stats' && e.parameter.pw === ADMIN_PW) {
      const sheet = SpreadsheetApp.openById(SHEET_ID).getSheetByName(SHEET_NM);
      const all   = sheet.getDataRange().getValues().slice(1).filter(r => r[0]);
      const rows  = all.map(r => ({
        date: r[0], name: r[1], cellGroup: r[2], attendance: r[3], message: r[4]
      }));
      const yes = rows.filter(r => r.attendance === '참석').length;
      const no  = rows.filter(r => r.attendance === '불참').length;
      return json({ success: true, total: rows.length, attending: yes, notAttending: no, rows });
    }
    return json({ error: 'unauthorized' });
  } catch(err) {
    return json({ error: err.message });
  }
}

function json(data) {
  return ContentService
    .createTextOutput(JSON.stringify(data))
    .setMimeType(ContentService.MimeType.JSON);
}

3SHEET_ID에 1단계에서 복사한 ID를, ADMIN_PW에 원하는 비밀번호를 입력하세요.

4저장(Ctrl+S) 후 상단의 배포 > 새 배포를 클릭하세요.

5설정:

항목값
유형 선택웹 앱
다음 사용자로 실행나(My Google Account)
액세스 권한모든 사용자 (Anyone)

6배포 후 나타나는 웹 앱 URL을 복사하세요.

3단계 — index.html에 URL 붙여넣기

index.html 파일을 메모장 또는 VSCode 등으로 열고, 상단 CONFIG 영역을 찾아 수정하세요:

const CONFIG = {
  APPS_SCRIPT_URL : '여기에_웹앱_URL_붙여넣기',
  ADMIN_PASSWORD  : 'admin1234',  // Apps Script의 ADMIN_PW와 동일하게
  ...
};
APPS_SCRIPT_URL과 ADMIN_PASSWORD 값이 Apps Script 설정과 일치해야 합니다.

4단계 — Netlify로 배포하기

1netlify.com에 접속해 무료 가입하세요.

2로그인 후 대시보드에서 "Add new site > Deploy manually"를 클릭하세요.

3아래 점선 영역에 중종로공동체 폴더를 드래그앤드롭하세요.

4배포가 완료되면 https://random-name.netlify.app 형태의 URL이 생성됩니다.

5원한다면 Site settings > Change site name에서 주소를 변경할 수 있습니다.
예: jungjongro2026.netlify.app

파일을 수정한 후 다시 배포하려면 Netlify 대시보드에서 같은 방법으로 폴더를 다시 드래그하면 됩니다.

자주 묻는 것

앱스크립트 URL을 넣지 않아도 페이지가 작동하나요?

네. URL을 비워두면 RSVP 응답이 해당 기기의 로컬 저장소에만 저장됩니다. 관리자 통계는 해당 기기에서 응답한 데이터만 보입니다.

RSVP 중복 방지는 어떻게 작동하나요?

브라우저의 LocalStorage에 기기 고유 ID를 저장하고, 재방문 시 이미 응답한 것으로 처리합니다. 앱스크립트가 연결된 경우 서버에서도 기기 ID 중복을 확인합니다.

관리자 버튼은 어디에 있나요?

페이지 오른쪽 하단 막대 그래프 아이콘 버튼을 누르면 관리자 패널이 열립니다. 비밀번호 입력 후 RSVP 통계를 확인할 수 있습니다.

카카오톡 공유가 잘 되나요?

모바일에서 "초청장 공유" 버튼을 누르면 카카오톡 포함 모든 앱으로 공유할 수 있는 공유 창이 열립니다. PC에서는 링크가 클립보드에 복사됩니다.
